    YOLOv8¶

    Github Link: ultralytics/ultralytics: Ultralytics YOLO11 🚀
    Paper Title: None
    Paper Link: None

    Intro:
    YOLOv8 由 Ultralytics 公司在 YOLOv5 （也是Ultralytics公司开发的）的架构基础上拓展、改进而来，与前身的主要区别在于使用了 Anchor-free 的设计，这加速了非极大值抑制（Non-Maximum Suppression, NMS）的后处理过程

    Inno:
    - Anchor-free
    - Automatic Mixed Precision Training
    - Adaptive Non-Maximum Suppression (one of post-processing methods)

    Model Size:
    - Nano、Small、Medium、Large、xLarge
    - The basic model structure is independent of its size(shown as the following figure). The difference is model's depth and width, controlled by the variables w(width multiplier), d(depth multiplier) and r(channel multiplier\expand ratio).

    Input¶

    Backbone¶

    Backbone mainly plays a role in extracting multi-scale features from input images. Multi-scale features means hierarchical features that represent both low-level textures and high-level semantic information.

    Architecture:
    - CSPDarknet

    Block: Conv¶

    ![[Pasted image 20250418165332.png|200]]

    Figure Structure of Conv Block

    Layer: Conv2d¶

    2d there means applying convolution to two spatial dimensions， typically width and height

    Params:
    - k: kernel size
    - s: stride
    - p: padding
    - c: channels num of input

    Layer: BatchNorm2d¶

    BatchNorm2d standardizes the features in each small batch of data, making the mean of each dimensional feature in the small batch close to 0 and variance close to 1, ensuring that the data passing through the network is not too large or too small, which is benificial for improving training stability and convergence speed.

    Activation: SiLU¶

    SiLU(Sigmoid Linear Unit), a speciallity of Swish, when \(\beta=1\).

    \[ SiLU(x) = s·\sigma(x) = \frac{x}{1+e^{-x}} \]

    Block: Bottleneck¶

    In deep neural network, especially in ResNet, Bottleneck is a commonly used module design. Bottleneck Block aims to reduce the number of parameters and computation complexity while preserving the performance of the model.

    ![[Pasted image 20250421101755.png]]

    Figure Structure of Bottleneck Block

    Params:
    - shortcut: if apply skip connection

    典型的瓶颈结构是由3个Conv Block组成的，先通过一个1×1 Conv Block减少通道数（如压缩至1/2或1/4），降低计算量；再通过一个3×3 Conv Block进行特征提取；最后再通过一个1×1 Conv Block升维，恢复表达能力。

    Bottleneck Block in YOLOv8 is not a typical structure

    Block: C2f¶

    The backbone of YOLOv8 is based on an advanced version of CSPDarknet. CSP means Cross Stage Partial, and its core idea is to split the feature map into two parts. One part is directly applied shortcut connection to perserve original information, while the other part extracts features through mutilple convolutional layers. Finally, the two or more parts of features will be concated. The algorithm can reduce computation complexity and alleviate the problem of gradient vanishing.

    The structure of CSP is widely used. For example, the C3 module is used in YOLOv5. C2f is a module similar to C3 but different from it. C2f further integrates multi-scale features based on CSP and optimizes gradient flow. C3 and C2f are all important blocks in CSPDarknet.

    ![[39130b64df9443d570b6ba01959ba6c.jpg|500]]

    Figure Comparison between C3 and C2f

    Neck¶

    Neck module in YOLOv8 refines and fuses the multi-scale features extracted by the backbone.

    Architecture:
    - FPNet (Feature Pyramid Network): one-way, Top-Down
    - PANet (Path Aggregation Network): two-way, Top-Down and Bottom-Up

    ![[Pasted image 20250419134334.png]]

    Figure Structure of Neck

    Head¶

    Head module is responsible for generating the final predictions, including BBox(bounding box) coordinates, object confidence scores, and class labels, from the refined features.

    YOLOv8 has 3 decoupled heads. Decoupled head means that classification and regression are not implemented in a 1×1 convolution. Each head has 2 branches to predict the BBox and the classes.
