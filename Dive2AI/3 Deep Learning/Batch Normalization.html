    Batch Normalization

    1 Introduction¶

    "Training Deep Neural Networks is complicated by the fact that the distribution of each layer’s inputs changes during training, as the parameters of the previous layers change. This slows down the training by requiring lower learning rates and careful parameter initialization, and makes it notoriously hard to train models with saturating nonlinearities." This phenomenon is refered to Internal Covariate Shift (ICS).1

    Why ICS leads to the use of only small lr and careful parameter initialization?
    Deepseek:

    您问到了一个非常本质的问题。我之前用“崎岖的损失平面”来比喻ICS的后果，现在我们来深入探讨一下为什么内部协变量偏移会导致这种局面。

    这背后的核心原因是：ICS破坏了梯度下降优化算法所依赖的一个基本假设——即参数的微小更新只会引起损失的微小变化。

    让我们从梯度下降的基本原理和ICS的破坏性两个方面来理解：

    1. 梯度下降的理想世界（没有ICS）

    在理想的优化问题中，损失函数 L(Θ) 是平滑的。当参数 Θ 发生一个微小的更新 ΔΘ 时，损失的变化 ΔL 也是微小且可预测的。

    • 局部线性假设：梯度下降算法在计算梯度 ∇L(Θ) 时，隐含地假设在当前点 Θ 的一个极小邻域内，损失函数是局部线性的。这意味着梯度 ∇L(Θ) 在这个小区域内是一个很好的预测器，指向损失下降最快的方向。

    • 稳定的学习：基于这个假设，我们相信沿着 -∇L(Θ) 方向走一小步（由学习率 η 控制），会 reliably 地到达一个损失更低的点 L(Θ - η∇L(Θ))。

    比喻：这就像在一個天气晴朗、地形缓和的丘陵地带下山。你能清楚地看到脚下的坡度（梯度），并且确信迈出一小步后，所在的新位置肯定会比现在更低。

    1. ICS制造的混乱世界（损失平面变得崎岖）

    ICS彻底打破了“局部线性”的假设。因为当网络参数 Θ 发生微小变化 ΔΘ 时，它不仅影响了本层的输出，还通过链式反应剧烈地改变了后面所有层的输入分布。

    这导致了两个直接后果，使得损失平面变得崎岖：

    后果一：梯度计算的“过期”问题

    • 发生了什么：在计算梯度时，我们是在当前参数 Θ 和当前网络激活分布 下计算出的 ∇L(Θ)。这个梯度指示了“在当前的输入分布下，如何更新参数能降低损失”。

    • ICS的破坏：一旦我们根据这个梯度更新了参数（Θ -> Θ'），前面层的输入分布会立刻发生剧变（ICS）。这意味着我们刚刚计算出的梯度 ∇L(Θ) 瞬间就“过期”了——它是在“旧世界”的地图上为你指的路，而你更新参数后一步就迈进了“新世界”。

    • 为何导致“悬崖”：这个“过期”的梯度可能在新世界的分布下完全失效，甚至是有害的。它可能指引你走向一个在旧分布下是低谷，但在新分布下却是悬崖的方向。一个大步更新（高学习率）可能会让你从“小下坡”直接掉进“万丈深渊”，导致损失暴涨（这就是“悬崖”）。

    后果二：参数更新的“协同”问题

    • 发生了什么：神经网络是一个高度复杂的系统，层与层之间需要紧密协同。每一层都在努力适应它当前的输入分布，并为其下一层产生一个有用的输出分布。

    • ICS的破坏：当一层根据梯度更新其参数时，它的本意是改善自己的任务。但由于ICS，这个更新会粗暴地改变其后面所有层的输入分布。这好比一个团队的成员在不知会队友的情况下，突然改变了自己的工作产出格式。

    • 为何导致“山谷”：后面层的参数是为了适应_旧的_输入分布而优化的。当分布突然改变，这些参数瞬间就变得不最优了，甚至完全错误。整个网络的协同被打破，性能下降（损失升高）。为了重新实现协同，网络可能需要一系列非常特定、精确的参数组合（狭窄的“山谷”），而梯度下降很难找到这些精确的点。

    总结¶

    所以说，ICS导致损失平面崎岖的原因并不是它凭空创造了更多的局部极小点，而是因为它：

    1. 使梯度信息迅速失效，让参数更新变得不可预测和危险，容易坠入“悬崖”。

    2. 破坏了网络层间的协同优化，使得整个网络难以稳定地收敛到一个平坦的优良解，反而容易被困在需要精确协同的“狭窄山谷”中。

    BN通过稳定每一层的输入分布，确保了参数 Θ 的微小更新只会引起损失的微小、可预测的变化，从而平滑了损失平面，使得梯度下降这个局部优化器能够安全、高效地工作。

    In summary, ICS will lead to the use of only small lr and careful initialization

    2 Contribution¶

    • allow to use much higher learning rates then speed up training process, by reducing the dependence of gradients on the scale of the parameters
    • be less careful about initialization, by reducing the dependence of gradients on the scale of the parameters' initial values
    • act as a regularizer, in some cases eliminating the need for Dropout
    • make it possible to use satutating onolinearities by preventing the network from getting stuck in the saturated modes
    • with BN, the shift \(b\) in linear transformation \(Wx+b\) can be ignored since its effect will be canceled by the subsequent mean subtraction.

    3 Methods¶

    3.1 Training with BN¶

    For a layer with \(d\)-dimensional input \(x=(x^{(1)},x^{(2)},...,x^{(d)})\), we will normalize each dimension
    $$
    \hat{x}^{(k)}=\frac{x^{(k)}-E[x^{(k)}]}{\sqrt{Var[x^{(k)}]}}
    $$
    Specifically, for a mini-batch \(\mathbb{B}\) with \(m\) values, i.e.
    $$
    \mathbb{B}={x_1..._m}
    $$
    Algorithm: Batch Normalizing Transform, applied to activation \(x\) over a mini-batch.
    Input: Values of \(x\) over a mini-batch: \(\mathbb{B}=\{x_1..._m\}\); Parameters to be learned \(\gamma^{(k)}\), \(\beta^{(k)}\).
    Output: \(\{y_i=BN_{\gamma^{(k)},\beta^{(k)}}(x_i^{(k)})\}\).
    \(\mu^{(k)}_{\mathbb{B}}←\frac{1}{m}\sum^m_{i=1}x_i^{(k)}\) // mini-batch mean
    \(\sigma^{(k)^2}_{\mathbb{B}}←\frac{1}{m}\sum^m_{i=1}(x_i^{(k)}-\mu^{(k)}_{\mathbb{B}})^2\) // mini-batch variance
    \(\hat{x_i}^{(k)}←\frac{x_i^{(k)}-\mu^{(k)}_{\mathbb{B}}}{\sqrt{\sigma^{(k)^2}_{\mathbb{B}}+\varepsilon}}\) // normalize
    \(y_i^{(k)}←\gamma^{(k)}\hat{x_i}^{(k)}+\beta^{(k)}\) // scale and shift
    where, \(\varepsilon\) is a constant for numerical stability, \(\gamma^{(k)}\), \(\beta^{(k)}\) are learned parameters which restore the network's ability to represent the identity transformation.

    3.2 Inference with BN¶

    In the inference stage, we want the output only depends on the input, deterministically. For this, we use population, rather than mini-batch, statstics. We can use the unbiased variance estimation \(Var[x^{(k)}]=\frac{m}{m-1}E[\sigma^{(k)^2}_{\mathbb{B}}]\). However, in practice, we perfer to use moving averages instead. This is so called running mean and running variance. We can track the accuracy of a model as it trains. Since the means and variances are fixed during inference, the normalization is simply a linear transform applied to each activation.

    3.3 Convolutional Networks with BN¶

    For convolutional layers, we additionally want the normalization to obey the convolutional property – so that different elements of the same feature map, at different locations, are normalized in the same way. To achieve this, we jointly normalize all the activations in a minibatch, over all locations. In Alg. 1, we let \(\mathbb{B}\) be the set of all values in a feature map across both the elements of a mini-batch and spatial locations – so for a mini-batch of size \(m\) and feature maps of size \(p × q\), we use the effective mini-batch of size \(m^′ = |\mathbb{B}| = m · p q\). We learn a pair of parameters \(γ^{(k)}\) and \(β^{(k)}\) per feature map, rather than per activation.
