    Visual Studio 2022¶

    Introduction¶

    本人在进组后，与一位师姐一起用VS 2022开发了一款C++ Windows桌面软件。由于不熟悉IDE，在配置环境和交接代码的过程中走了很多弯路，在此记录一下本人自己摸索出来的IDE使用最佳实践，避免重蹈覆辙。

    Implementation¶

    包含文件目录和库目录设置¶

    C++工程需要.h头文件和.lib库文件，对应的目录分别是包含文件目录和库目录。VS中设置包含文件目录和库目录的地方总共有两处，分别是VC++ >> 包含目录、VC++ >> 库目录和C/C++ >> 附加包含目录、链接器 >> 常规 >>附加库目录。

    ![[VS包含目录和库目录设置.png]]
    ![[VS附加包含目录设置.png]]
    ![[VS附加库目录设置.png]]

    关于这两种配置方式的区别，我个人在使用的过程中没有太大感觉。查到的一些说法是两种方式的优先级不同，更推荐使用C/C++ >> 附加包含目录和链接器 >> 常规 >>附加库目录。

    MSVC编译器查找文件的顺序是：
1. 当前文件所在目录
2. `附加包含目录`（C/C++）
3. `VC++ 包含目录`
4. 系统环境变量（INCLUDE）

    路径设置技巧¶

    项目中使用到的包含目录、库目录的路径最好设置成相对路径，这样在拷贝工程或者从git仓库上clone时就不必再去额外改动这些路径了，能够提升开发效率。相对路径的设置可以借助VS系统配置里的一些宏来实现，例如：$(SolutionDir)等。
